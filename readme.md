### Lab 01: Search Algorithms

Lab 01 explores **uninformed search algorithms** using an airport route dataset.

Algorithms covered:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Uniform-Cost Search (UCS)

The experiment compares the algorithms based on:

- Number of hops
- Path cost
- Nodes expanded
- Maximum frontier size
- Runtime
